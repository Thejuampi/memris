# Memris 0.3.0

This release brings the Gradle build, numeric and string query fixes, Spring
startup and packaging corrections, and the centralized real-world test suite
since 0.2.4. Java 21 remains required.

## Query correctness

- Exclusive int/long bounds handle minimum and maximum values without overflow,
  including scans, indexes, residual filters, count, and exists queries.
- Six disabled e-commerce cases are active again. Case-insensitive patterns use
  locale-independent normalization; `LikeIgnoreCase` and empty ordered results
  execute correctly.
- `EqualsIgnoreCase`, `IsIgnoreCase`, `AllIgnoreCase`, `IsNotNull`, and `removeBy`
  have executable repository coverage. Equality ignoring case uses the same
  locale-independent comparison in scans and generated residual filters.

## Spring and packaging

- Both Spring generations support repository discovery, generated method
  delegation, Memris IDs, converter round trips and nulls, named arenas, and
  context cleanup.
- Required Spring transaction infrastructure and the matching persistence API
  are published transitively. Boot 2 keeps Spring 5/`javax`/SLF4J 1; Boot 3 keeps
  Spring 6/`jakarta`/SLF4J 2.
- Independent core, Boot 2, and Boot 3 applications verify packaged artifacts
  through both Gradle module metadata and Maven POMs before publication.

## Development and verification

- Gradle wrapper replaces the Maven reactor; artifact coordinates remain under
  `io.github.thejuampi`. Core is still `memris`.
- Public behavior is centralized in real-world scenarios across bytecode and
  method-handle tables, with runtime codegen enabled and disabled. Focused unit
  tests retain internal corner cases and concurrency protocols.
- Static-analysis failures are corrected; JMH and concurrency guardrails remain
  part of verification. README and roadmap distinguish implemented behavior
  from longer-term proposals.
- Release automation validates all five publications, publishes signed
  artifacts, records the matching tag and GitHub Release, updates dependency
  examples, and advances the development snapshot.

## Upgrading

Use version **0.3.0** for `memris`, `memris-spring-data-boot2`,
`memris-spring-data-boot3`, `memris-spring-boot-starter-2`, and
`memris-spring-boot-starter-3`. Choose the starter matching the application's
Spring generation.

The storage metadata contract uses Memris annotations. The JPA converter bridge
does not normalize JPA entity mappings. Heap storage, eager relationships, and
arena lifetimes retain their existing behavior; persistence, transactions, and
snapshot isolation remain outside this release. See [CONCURRENCY.md](../CONCURRENCY.md)
and [SPRING_DATA.md](../SPRING_DATA.md) for those boundaries.
